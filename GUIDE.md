# urlsyntax 1.0 API guide

Install with `pip install urlsyntax`. Python 3.10 or later is required.
The complete public surface is `HttpURL`, `InvalidURLError`, `Scheme`, `HostKind`,
`Reason`, `parse_http_url`, `is_valid_http_url`, `normalize` and `resolve`.

`parse_http_url(value, *, allow_userinfo=True)` accepts a string and returns a frozen,
hashable `HttpURL`. `normalize(value)` returns its string form. Both raise
`InvalidURLError` for invalid strings and `TypeError` for non-strings.
`is_valid_http_url(value, *, allow_userinfo=True)` returns `False` for non-strings
or invalid strings. The option follows normal Python truth testing.

`resolve(base, reference)` accepts two strings and returns an HTTP(S) target using
the strict RFC 3986 algorithm. It validates the base, reference and target. It keeps
the original case, escapes and explicit default port, so call `normalize` separately
when needed. Empty references remove the base fragment. Non-strings raise `TypeError`.

```python
from urlsyntax import normalize, parse_http_url, resolve

url = parse_http_url("https://User@Example.com:443/a/../b?#")
print((url.host, url.port, url.effective_port))  # ('example.com', None, 443)
print((url.query, url.fragment))  # ('', '')
print(resolve("HTTP://Example.com:80/a/b", "../c"))  # HTTP://Example.com:80/c
print(normalize(resolve("HTTP://Example.com:80/a/b", "../c")))  # http://example.com/c
```

`HttpURL(scheme, userinfo, host, host_kind, port, path, query, fragment)` stores those
eight fields as given. Direct construction does not validate or normalize them:
prefer the parser. Equality, hashing and pickling use the stored fields.
`effective_port` returns an explicit port (including zero), otherwise 80 or 443.
`str(url)` adds IPv6 brackets and preserves absent versus empty delimiters.
The repr and normal form can contain credentials; do not log them as safe diagnostics.

`Scheme` is `Literal["http", "https"]`; `HostKind` is
`Literal["name", "ipv4", "ipv6"]`. `Reason` is the closed set of eighteen codes
listed in the [README](https://github.com/JaviLianes8/urlsyntax#reasons).
These aliases are typing values, not constructors. Their runnable examples live in
the package docstring. `InvalidURLError(reason)` accepts a declared `Reason`, inherits
`ValueError`, exposes `.reason` and pickles with it. Messages contain no input.
Constructing an error with an undeclared code is outside the typed contract.

## Scope and safety

Only ASCII URI text is accepted. Encode international names and text before calling.
No DNS query or network request is made. A syntactically valid private address is still
valid here; access control, redirects and DNS rebinding protection belong to the caller.
The browser agreement claim is limited to accepted ASCII hosts and the documented
serialization differences. This is not a general WHATWG URL parser.

Normalization decodes unreserved escapes, capitalizes remaining escape hex digits,
removes dot segments, lowercases scheme and host, removes empty/default ports and
adds `/` to empty paths. Query order, empty delimiters, case outside scheme/host,
reserved escapes and trailing slashes remain meaningful.

## Command line and upgrade from 0.2.1

`python -m urlsyntax` and `urlsyntax` accept URL arguments or one URL per stdin line.
Blank lines are skipped. `--check` suppresses normal forms; `--no-userinfo` rejects
even empty userinfo. Exit status: 0 success, 1 invalid input, 2 invalid usage.
Invalid-input stderr now contains only `invalid (reason)`; usage diagnostics omit
arguments. Successful stdout still contains the requested normal forms, including
credentials when present. `TypeError` messages no longer include arbitrary type names.
The incidental `annotations` attribute is gone. All other public behavior is retained.

## Reproducing verification

Install development dependencies with `pip install -e .[dev]`.
Set `URLSYNTAX_UPSTREAM` to a scratch directory, then run
`python scripts/fetch_upstream.py`. Downloads are hash-checked against the tracked
manifest; upstream tests skip cleanly without them. The full texts and corpora are
never distributed. RFC example values are short cited extracts; other cases are
hand-written or generated by seeded tests.

Run `ruff format --check .`, `ruff check .`, `mypy --strict src tests` and
`python -m pytest --basetemp <scratch-directory>`. Each test has a 300 second limit.
Set `URLSYNTAX_E2E=1` for wheel building, installation and CLI subprocess tests;
set `URLSYNTAX_E2E_PYPI=1` as well for the live 0.2.1 upgrade test.
Set `TEMP` and `TMP` to the scratch directory when build tools must use it too.
